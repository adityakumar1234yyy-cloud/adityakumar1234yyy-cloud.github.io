# Aditya Kumar — Data Analyst Portfolio

A responsive, dependency-free portfolio for GitHub Pages. Includes the verified Titanic GitHub project, Cyclistic results from the resume, the exact Tableau Public profile, LinkedIn, GitHub, email, phone and a downloadable resume.

## Publish on GitHub Pages
1. Create a public repository named `adityakumar1234yyy-cloud.github.io` under the GitHub account `adityakumar1234yyy-cloud`.
2. Upload `index.html`, `styles.css`, `.nojekyll` and the `assets` folder at the repository root.
3. Open Settings → Pages. Choose **Deploy from a branch**, then **main** and **/(root)**, and save.
4. Wait for GitHub's Pages deployment to succeed. The expected address is `https://adityakumar1234yyy-cloud.github.io/`.

The site has not been published by preparing these files. No custom domain or paid hosting is required.
